## ✨ Features

- **Diurnal Lighting Controls**: Seamless toggle between Midday, Sunset Gold, and Midnight Moon spatial ambience.
- **Double-Bezel Framing**: Architectural concentric bevels echoing Swiss luxury craftsmanship.
- **Integrated Studio CMS** (`/admin`):
  - **Monographs & Essays**: Full CRUD management for architectural publications.
  - **Estate Dossiers**: Create, edit, and categorize residences across Lakefront, Coastal, and Alpine territories.
  - **Headlines & Principles**: Live editor for hero messaging and spatial pillars.
  - **Acquisition Inquiries**: Private client lead management with status updates (New, Reviewed, Contacted, Archived).
  - **Media Assets**: Categorized visual media library with instant preview.
  - **Data Utilities**: 1-Click JSON export, import, and factory reset.
- **Interactive 360° Virtual Tour**: Spatial room exploration with Day/Twilight lighting modes and ambient audio simulator.
- **Confidential Acquisition Modal**: Swiss NDA-sealed inquiry flow with location and investment tier selection.
- **WordPress 6.x Theme Bundle**: Complete PHP theme mirror included in `/wordpress-theme`.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Aureo Palette
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Netlify (Automated CI/CD with SPA Routing)

## 🚀 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/rushikeshnarule/aureo-residences.git

# Navigate into project directory
cd aureo-residences

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
