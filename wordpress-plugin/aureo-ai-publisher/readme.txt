Automated daily AI business publisher powered by Google Gemini 2.5 Flash.

== Description ==
Aureo AI Daily Post Publisher creates 1-2 SEO-optimized business monographs, market analyses, or architectural pieces every day automatically via WP-Cron.

= Features =
* Direct Google Gemini API (2.5 Flash / 1.5 Flash fallback).
* Fully automated daily or twice-daily publishing via WP-Cron.
* Any custom business niche (Luxury Architecture, Real Estate, Wealth, Tech, etc.).
* Automated featured image attachment from curated high-resolution photography.
* Instant "Generate Now" trigger from WordPress Admin.
* Full HTML formatting with H2/H3 headings, pullquotes, and bullet points.

== Installation ==
1. Upload aureo-ai-publisher.zip via Plugins > Add New > Upload Plugin.
2. Activate the plugin.
3. Configure your API key & niche in **AI Auto Publisher** in the WordPress admin menu.
