== Description ==

Aureo is an ultra-luxury WordPress theme designed for high-end architecture ateliers, monolithic estate portfolios, and private residential developers.

Key Features:
- Ambient Video Hero Header with live motion controller
- Seamless gradient mask fading into pure white
- 3 Destination Dossiers (Zurich, Costa Brava, Aspen)
- Monolithic Residences carousel with interactive spatial hotspots
- 360° Virtual Tour Modal with Day/Twilight lighting explorer
- Dynamic WordPress Posts loop & custom Post Type (Residences)
- Swiss NDA Confidential Acquisition Inquiry Modal with AJAX submission
- Modern serif typography (Cormorant Garamond & Cinzel) paired with Plus Jakarta Sans

== Installation ==

1. Download the `aureo` folder or compress it into `aureo.zip`.
2. In your WordPress Admin Dashboard, navigate to:
   Appearance > Themes > Add New > Upload Theme.
3. Choose `aureo.zip` and click "Install Now".
4. Activate the theme.
5. In Settings > Reading:
   Set "Your homepage displays" to "A static page" and select your Front page.
